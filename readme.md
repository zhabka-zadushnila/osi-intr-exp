# Лабораторная работа
Пояснения к содержанию:

Основные артефакты - [osi-intr-exp-01-5.pdf](https://github.com/zhabka-zadushnila/osi-intr-exp/blob/main/osi-intr-exp-01-5.pdf) (итоговый отчёт) и log.md (рукописный лог моих размышлений и действий по ходу работы)

- environment* - разные версии shell скриптов использовавшиеся в процессе
- results*.csv - итоговые csv метрики
- stage-1.sh - самописный скрипт первичного запуска
- stage-1-run.sh, stage-2-run.sh - сгенерированные скрипты по образу и подобию stage-1.sh
- stage*.ipynb - сгенерированные ipynb ноутбуки для быстрого ознакомления с полученными данными.
